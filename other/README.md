# other/

This folder contains the following files:

- `setup_ssh.bat` The ssh setup script for windows devices that adds the robot's secret key to the known hosts. This simplifies future connections so that the user does not have to type the password again.
- `stream.html` The html file for the stream viewer. Open it in the default browser to connect to the robot stream.
- `upload.sh` Script to upload the program files to the robot. For apple devices.
- `gyro/` This folder contains gyro calibration data sets and a Python script to visualize them.
