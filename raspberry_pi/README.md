# raspberry_pi/

This folder contains the following files:

- `car.service` This file contains the automatic startup service for the robot program on Raspberry Pi devices.
- `config.json` The configuration file for the robot program in JSON format.
- `config.py` This file reads the config.json file.
- `helpers.py` This file contains helper functions for the robot program.
- `pipeline.py` This file contains the image processing pipeline for the robot program.
- `roi.py` This is the current main file. <!-- Changed main file from roi.py to main.py -->
- `rounddir.py` This file contains functions to handle round direction detection.
- `setup_autorun.sh` Script to set up the robot program to run automatically on startup.
- `setup_networking.sh` Script to set up the networking for the robot.
- `tests/` This folder contains some scripts to test the robot.
